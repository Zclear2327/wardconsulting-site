The rule we intend to keep

A person approves what cannot be casually undone.

This is the same idea as How it works. For the hosted service, these four actions would wait for a human yes. Silence would not count as a yes. The list is the plan. There is no live control panel on this website to try.

1

Sends

A message to a customer, partner, or list would wait before it goes out.

2

Publishing

3

Spend

Anything that moves money would wait before it is spent.

4

Permanent changes

A change that cannot be undone would wait for a person's yes.
