How every agent works

Checked before it acts. Logged after.

This is the loop each agent runs on every job. It is why the fleet can be trusted with live ad budgets and customer email.

  1. DraftThe agent does the work: a bid change, a title, a reply.
  2. ScoreA critic grades the draft 0–10 against the job's rules.
  3. ReviseAnything below the bar gets rewritten, or held for you.
  4. ActOnly passing work goes live, inside set spending limits.
  5. LogEvery run is written down, so you can see exactly what happened.
